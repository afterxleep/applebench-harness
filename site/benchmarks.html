Reading these numbers. Pass rate is the first comparison: how many tasks reached a verified result. Points take those solves and shrink them when a task went over the token allowance, so two close point shares can hide a wide gap in what was actually finished. Cost is reported separately, because provider prices move and a score that moved with them would be measuring the wrong thing. A number only means something alongside the conditions: which suite, which model, which harness, which Xcode, and which attempt counts. Every run page states those, plus the scoring specification the points were computed under.
