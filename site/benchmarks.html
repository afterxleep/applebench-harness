Scores default to each model's default or provider-suggested effort

The headline results run every model at its default effort, or the effort its provider suggests, because that is how most people actually use it. Each model's effort is shown beside its score. Runs at other settings, such as higher effort or different permission modes, will be added as separate, clearly labelled results, never mixed into these.

The score is a living number

The score is a living number. Under the empirical-v1 specification each task is weighted by how rarely the complete published models pass it — a task everyone solves is worth 100 points, a task almost nobody solves is worth up to 2000. Adding another complete model changes those weights, so every model — including ones published earlier — is rescored without being rerun. The raw pass rate is always shown beside the score, and the full weight table is published.
